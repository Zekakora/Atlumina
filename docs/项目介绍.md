# 项目需求规范说明书 (PROJECT_SPEC.md)

## 一、 项目概述 (Overview)
本项目旨在开发一款基于 **WinUI 3 (Windows App SDK)** 的现代 Windows 本地专业相册管理工具。
应用采用 **Fluent 2 Design System**，支持海量照片/RAW 文件的高效查看、GPS 地图显示、EXIF 编辑，并依托 Windows 本地 NPU (DirectML) 进行智能照片分析与清理。

---

## 二、 技术选型与依赖库 (Tech Stack)

### 1. 基础架构与 UI
* **开发语言与框架**：C# / .NET 8+ / WinUI 3 (Windows App SDK)
* **UI 架构**：MVVM 模式
* **设计语言**：Fluent 2 Design (内置 Mica 材质、Acrylic 亚克力透光、软角圆角、Fluent 图标库)
* **海量列表优化**：使用 WinUI 3 原生 `ItemsRepeater` / `GridView` 开启 UI 虚拟化 (Virtualization)

### 2. 图像解码与元数据处理
* **EXIF 解析**：使用 NuGet 包 `MetadataExtractor`（高性能只读）
* **EXIF 修改/写入**：基于 `System.Diagnostics.Process` 封装 **ExifTool CLI**，确保 RAW 与常规格式元数据安全写入
* **RAW 文件解码**：
  * **快速预览**：优先通过 **Windows Imaging Component (WIC)** 提取 RAW 内置的 Jpeg/Exif 预览帧
  * **深度解码**：结合 `LibRaw.NET` 或 WIC 原生解码器实现 Bayer 阵列完整渲染

### 3. 本地 NPU / AI 推理
允许在设置中禁用该功能
* **推理引擎**：`Microsoft.ML.OnnxRuntime.DirectML`
* **硬件加速**：优先调用 Windows NPU（通过 DirectML 调度），自动支持降级到 DirectML (GPU) 或 CPU

### 4. 地图与可视化
* **渲染内核**：内置 `WebView2` 控件
* **前端引擎**：`Leaflet.js` 或 `MapLibre GL`（搭配免 API Key 的开源矢量图层）
* **海量点聚类**：前端引入 `Supercluster` 算法进行动态点位聚合

## 三、 核心功能与实现方案 (Core Features)

### 1. RAW 文件与海量照片高性能查看
* **分级加载机制**：
  * **网格/预览层**：仅加载 256px / 1080p 的 WebP 缓存缩略图或 RAW 内置 Preview 帧。
  * **原图/放大层**：双击进入全屏时，异步调用 `LibRaw`/`WIC` 深度解码。
* **三级缓存架构**：
  * **L1 内存缓存**：基于 LRU (Least Recently Used) 策略，仅保留可视区域及前后视场内的 Bitmap。
  * **L2 磁盘缓存**：SQLite 数据库索引元数据，本地磁盘目录存储预生成的 WebP 缩略图。
  * **L3 原始文件**：磁盘物理路径，仅在深度查看/导出时读取。

### 2. 地图视图与 GPS 交互
* **交互逻辑**：C# 与 WebView2 通过 `PostMessage` 进行双向异步通信。
* **坐标标记**：读取照片 EXIF 中的 GPS 经纬度，动态送入地图。
* **渲染优化**：高空视角下自动聚类为数字点，缩放到近地面时平滑拉开显示单张/多张缩略图。

### 3. 本地 NPU 图像分析与清理助手
* **相似照片 / 连拍清理**：
  * **Stage 1 (粗筛)**：计算图像 `pHash` (感知哈希) 距离，快速提取高相似度候选组。
  * **Stage 2 (精筛)**：经 NPU 调用轻量级 **MobileNetV4 / MobileCLIP** 提取 Feature Embedding，计算余弦相似度。
* **模糊与瑕疵照片检测**：
  * **基础判定**：计算拉普拉斯方差 (Laplacian Variance)，评估边缘锐度。
  * **深度打分**：通过 DirectML 加载轻量化 **NIMA (Neural Image Assessment)** ONNX 模型，输出美学与技术质量评分。

### 4. EXIF 元数据拓展与编辑
* **修改范围**：支持批量修改拍摄时间、相机/镜头型号信息、ISO、快门速度、GPS 坐标补全、自定义 Tag/星级评分。
* **底座执行**：构造安全参数集，后台无窗口调用 `ExifTool` 进程执行修改，防锁死防损坏。

### 5. 外部 RAW 编辑器集成 (在 Camera Raw 中编辑)
* **入口**：右键菜单 / 查看器工具栏提供 “在 Camera Raw 中编辑”。
* **实现**：探测本机 Adobe 应用（Photoshop / Bridge / Lightroom 或用户自定义默认 RAW 编辑器）安装路径，通过 `ShellExecute` 将选中的 ARW 原文件路径传给外部编辑器打开。
* **定位**：相册应用自身不做像素级编辑，RAW 精修交由 Camera Raw 等外部专业编辑器完成。

## 四、 进阶体验拓展功能 (Advanced Features)

1. **本地语义搜图 (CLIP Search)**：基于本地 NPU 运行 MobileCLIP 提取图像和文本向量，支持自然语言搜图（如“沙滩上的狗”）。
2. **本地人脸识别与聚类**：运行 `RetinaFace` + `ArcFace` ONNX 模型，本地识别人物并离线聚类生成“人物”相册。
3. **调色盘提取与色彩搜图**：基于 K-Means 算法提取照片主色调（5色盘），支持按“主色调”过滤照片。
4. **时间热力图与历史上的今天**：提供侧边栏 GitHub 风格时间热力图，主页展示“N 年前的今天”回忆卡片。
5. **GPS 轨迹匹配与批量补全**：支持导入手机 GPX 轨迹文件，根据拍摄时间自动把 GPS 坐标回写至单反照片 EXIF。

## 五、 工程规范与性能指标 (Engineering Guidelines)

1. **响应性要求**：主 UI 线程严禁执行任何 I/O 操作、RAW 解码或 AI 推理。所有重任务必须在后台 Task/线程池队列中异步运行。
2. **NPU 容错降级 (Fallback)**：
   * 启动 AI 引擎时检测 DirectML (NPU) 设备。
   * 若初始化失败，自动无缝降级为 DirectML (GPU) $\rightarrow$ CPU。
3. **Fluent 2 视觉要求**：
   * 主窗口开启 `MicaController`（云母背景材质）。
   * 导航栏使用 `NavigationView` 与 `Acrylic`（亚克力材质）。
   * 必须严格适配 Windows 浅色/深色模式无缝切换。
4. **主界面布局（阶段 2 定稿）**：
   * **顶部菜单栏**：导入 / 筛选 / 视图 / 工具 / 设置等命令。
   * **主体三栏式布局**：
     * **左栏（窄）**：文件夹目录树 + 标签 / 智能相册列表，可折叠。
     * **中栏（最大区域）**：照片浏览网格 / 时间线视图。
     * **右栏（窄）**：选中照片的大图预览 + EXIF 信息面板（含星级评分、标签编辑），可折叠。
